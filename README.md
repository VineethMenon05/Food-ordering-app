# 🍔 Food Ordering Web Application (Flask)

A full-stack web application built using Flask that allows users to browse food menus, view items, and simulate placing orders. This project demonstrates backend development, database integration, and dynamic content rendering.

---

## 🚀 Features
- 🍽 Browse restaurant menu  
- 🛒 Add/select food items  
- 📊 Dynamic content rendering using Flask  
- 🗂 Database integration (SQLite)  
- 🔄 CRUD operations for menu management  
- 🎨 Responsive UI using HTML & CSS  

---

## 🛠 Tech Stack
- **Backend:** Flask (Python)  
- **Database:** SQLite  
- **Frontend:** HTML, CSS  
- **Templating Engine:** Jinja2  
- **ORM (if used):** SQLAlchemy
